# avaliacao-unidade-1
## Evolução da Tecnologia
## Sobre o projeto
Este projeto foi desenvolvido como uma atividade avaliativa de HTML, com o tema Evolução da Tecnologia Durante as Décadas.

O objetivo é apresentar, de forma organizada, algumas das principais transformações tecnológicas e mostrar como diferentes tecnologias passaram a fazer parte do cotidiano.

Entre os assuntos abordados estão a história da tecnologia, tecnologias atuais, inteligência artificial, computação em nuvem e Internet das Coisas (IoT).
Páginas
Início: apresenta o tema principal do projeto.

## História: apresenta a evolução da tecnologia ao longo do tempo.

## Tecnologias: apresenta tecnologias atuais, como Inteligência Artificial, Computação em Nuvem e Internet das Coisas.

## Sobre: explica o objetivo e a proposta do projeto.

### Contato: possui um formulário para interação com o visitante.

### Recursos utilizados
Durante o desenvolvimento foram utilizados recursos de HTML, incluindo:

### Estrutura semântica com header, nav, main, section, article, aside e footer;

Tabelas com colspan;

Formulário com diferentes tipos de campos;

datalist;

details e summary;

figure e figcaption;

Listas ordenadas e não ordenadas;

abbr;

Elementos de marcação de conteúdo;

Arquivos de mídia;

Links para navegação entre as páginas.

## Organização
Os arquivos HTML foram separados na pasta html/, enquanto as imagens ficam na pasta img/. As pastas audio/ e video/ foram destinadas aos arquivos de mídia utilizados no projeto.

O projeto foi desenvolvido sem CSS, utilizando somente HTML, conforme os requisitos da avaliação.
